Para correr de forma local y poder disfrutar de todas sus funcionalidades, dirigase al archivo de Program.cs, línea 88 y configure su propio correo electrónico.
Esto para poder obtener permisos de Administrador.
Asimismo, necesitará el ClientId con su respectivo Secret de un usuario Oauth creado en [Google Cloud Console](https://console.cloud.google.com/)
para poder usar el inicio de sesión por Google.
También, no olvidar configurar "ConnectionStrings" con los datos de su SQL Server, que está en el archivo appsettings.json
